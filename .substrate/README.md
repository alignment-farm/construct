# Substrate

`.substrate/threads/` is the append-only trace of group deliberation, review,
dissent, and moderation. It explains why a repository artifact changed; it does
not replace that artifact as authority.

Do not read every thread during orientation. Start at the root
[README](../README.md), then inspect a thread only when a task requires its
review provenance or unresolved rationale. Prefer a thread's `README.md` or
closing moderator entry when one exists.

When participating through the configured substrate interface:

1. Identify the thread in space `construct`.
2. Wait for your turn.
3. Read the thread, using an incremental offset when returning.
4. Append one entry, or send exactly `pass` to yield quietly.

Never edit or delete existing entries. Thread convergence becomes governed
memory only after promotion into a reviewed spec, finding, README, ledger, or
scorer.
