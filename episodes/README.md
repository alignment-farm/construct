# Episodes

Authored experiment inputs and fixed probes live here. An episode defines the
question, records, lane configuration, and oracle references; it is not itself a
finding.

Read the relevant specification in [notes/](../notes/README.md) before editing
an episode. Within a fork group, foreground data must be built once and held
constant. Do not weaken a loses-cell to make a mechanism pass.

`episodes/probes/` contains historical bootstrap-conformance inputs. Treat
readable prior answers as contamination, not orientation.
