## Built surface

[`field_use.py`](../sketches/next_substrate/field_use.py) supplies a manual
library API for one independently motivated invocation:

```text
FieldUseCapture.start(...)
  -> freeze_pre_action(...)
  -> record_action(...)
  -> record_consequence(...)
  -> complete()
```

At any incomplete phase, `terminate(capture_refused | capture_confounded, ...)`
preserves the partial trace and prevents resume or replacement.

The exact normal event chain is:

```text
invocation_started
  -> encounter_observed
  -> field_use_pre_action_frozen
  -> field_use_action_referenced
  -> consequence_observed
  -> invocation_completed
```

Every event uses the existing `body-core-v0.2` envelope and remains
`wire_integration_only`. The store explicitly selects the literal
`body-core-v0.2-provisional-policy` projector. The field-use events are not
policy-mutating kinds, so they advance only the canonical cursor and do not
admit state.

## Fail-closed checks

The implementation refuses before the relevant append when:

- the protocol file no longer matches its endorsed SHA-256;
- an invocation id can escape `runs/field_use/` or would overwrite an existing
  ledger;
- eligibility was not declared by a human operator or external runtime;
- the acting model is named as encounter or consequence observer;
- shadow mode exposes lineage;
- consulted status has no consultation surface;
- negative non-use status silently carries a surface;
- declared `lineage_origin` disagrees with per-source provenance;
- a lineage reference escapes the repository, is missing, changes bytes, fails
  Core validation, or omits a declared record id;
- a projected-view digest disagrees with explicit replay;
- field-capture-only lineage claims independently motivated projected state;
- event order, writer route, authority, scope, causal chain, retention, or
  deterministic cost changes on replay;
- a completed or terminal partial trace is appended again.

Reference artifacts are content-pinned local repository files. Redacted
artifacts retain only digest, byte count, kind, and reason. The module copies no
prompt, patch, test log, or lineage content into an inline capture payload.

## Deliberate limits and broken glass

- The API is manual and library-level. It does not intercept prompts, commands,
  or model output and has no standing daemon or CLI.
- `lineage_origin`, operator identity, actor identity, and observer identity are
  declared runtime claims. Content and event structure are checked; principal
  identity and origin are not cryptographically authenticated.
- Retrievable v0 references resolve to local files inside the repository.
  External systems need a later explicit resolver rather than an opaque URL.
- A projected consultation accepts exactly one Body Core lineage in v0. Raw
  consultation may declare multiple independent and field-capture sources.
- The declared artifact revision is recorded but the implementation pins the
  bytes directly; it does not invoke Git to prove that revision contains them.
- The inherited Core remains single-process, unanchored, and quadratic on
  append/replay.
- The calendar clock now runs from the first admitted invocation; a start
  without a terminal native consequence remains non-evidence about outcome.

These limits are visible pressure points, not permission to repair ahead of
use. The implementation loses its reviewed meaning if it is mistaken for
automatic capture, authenticated provenance, causal evidence, or a pilot that
already contains field use.

## Non-goals

This build adds no field data, state admission, summarizer, new projector,
scorer, dashboard, engine call, automatic capture, anomaly entry, or frontier
reopening. Pilot authorization changes no reviewed implementation byte and
does not make an invocation eligible.
