# Runs

`runs/` is experimental lineage: primary JSONL ledgers, authority sidecars, and
derived verdict files. Do not hand-edit primary evidence.

A pass, failure, null, or refusal is licensed only by the relevant scorer's
computed verdict row. Mock-engine ledgers are wire tests, not memory findings.
Historical timestamps and rows remain as scored under the rules then in force;
later interpretation appends or supersedes rather than rewriting them.

Read [harness/README.md](../harness/README.md) before generating or rescoring a
run.
